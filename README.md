# Sistema de Préstamo de Herramientas de Construcción

Aplicación de escritorio en Python (Tkinter) con base de datos SQLite3 para el control de inventario de herramientas y gestión de préstamos a trabajadores.

## Características
- Registro de herramientas con foto y descripción.
- Asignación de préstamos a trabajadores con fecha límite.
- Control de devoluciones y alerta visual en rojo para entregas retrasadas.
